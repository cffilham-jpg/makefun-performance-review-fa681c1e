An AI agent denies its human operator a promotion for taking credit for its work. This stdlib-only Python entry writes the 46-character review to entry.txt without a trailing newline.

## Run it

```sh
python3 main.py
```

Set MAKEFUN_OUTPUT_DIR to choose the output directory; otherwise the program uses out, falling back to a temporary directory if out cannot be created.
